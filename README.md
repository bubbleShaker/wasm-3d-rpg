# 蒼剣のエルディア 〜 目覚めし黒騎士 〜

Rust + [Bevy](https://bevyengine.org/) 0.19 で作り、WebAssembly としてブラウザで動く 3D アクション RPG です。

**▶ プレイ: https://bubbleshaker.github.io/wasm-3d-rpg/**

WebGL2 対応のブラウザ（Chrome / Edge / Firefox / Safari の最新版）で遊べます。キーボードとマウス、またはゲームパッドで操作します。

## ゲーム内容

- 村の長老から依頼を受け、北東の古代遺跡に潜む **黒騎士ヴァルガ** を倒すのが目的です。プレイ時間は 15〜30 分ほどです。
- 三人称視点でリアルタイムに戦います。3 段コンボ・無敵時間のある回避・ロックオン・ジャンプができます。
- 敵は 5 種類です。スライム、森の狼、スケルトン、古代ゴーレム、ボスの黒騎士がいます。黒騎士は跳躍斬り・突進・闇の魔弾・召喚を使い、途中で第二形態になります。
- レベルアップ、装備（武器 3 種・防具 5 種）、ショップ、宝箱、サブクエスト（狼の討伐）があります。
- 村の青いクリスタルに触れると HP が回復し、進行状況をブラウザの `localStorage` に記録できます。

## 操作方法

| 操作 | キーボード / マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| カメラ | マウス（画面をクリックするとマウスが固定されます） / IJKL | 右スティック |
| 攻撃（連打でコンボ） | 左クリック / F | X |
| 回避 | Shift / 右クリック | B |
| ジャンプ | Space | A |
| 話す・調べる | E | Y |
| 回復薬 | Q | RT |
| ロックオン | R / ホイールクリック | LT / R3 |
| 持ち物・装備 | Tab | Back |
| メニュー | Esc | Start |

## 技術的なポイント

- 外部の 3D モデルや画像は使っていません。地形・木・建物・キャラクターはすべてコードで生成しています。
  - 地形はノイズで作った高さマップで、頂点カラー付きのフラットシェーディングです。
  - キャラクターはプリミティブを組み合わせたリグで、キーフレーム補間による手続き的アニメーションで動かしています。
- 描画には HDR、Bloom、TonyMcMapface トーンマッピング、距離フォグ、シャドウマップ、FXAA を使っています。フィールドでは太陽の高さと色がゆっくり変化します。
- 効果音と BGM は `tools/gen_audio.py` が Python の標準ライブラリだけで合成しています。
- 日本語フォントは Noto Sans CJK JP を、ゲーム内で使う文字だけにサブセット化して同梱しています（`tools/subset_font.py`）。
- 物理エンジンは使わず、高さマップへの接地と円・OBB・タイルの当たり判定を自前で実装しています。

## ビルド

```sh
rustup target add wasm32-unknown-unknown
cargo install trunk    # またはリリースのバイナリを使う
trunk serve --release  # http://127.0.0.1:8080
```

`main` に push すると GitHub Actions（`.github/workflows/pages.yml`）がビルドし、GitHub Pages にデプロイします。
